# Installing FLYER

FLYER is a free Shopify Online Store 2.0 theme by [KIOSK](https://kioskthemes.com).
Installing takes about two minutes.

## 1. Upload the theme

1. In your Shopify admin, go to **Online Store → Themes**.
2. Under **Theme library**, click **Add theme → Upload zip file**.
3. Select `flyer-theme.zip` (the file inside this download — not the outer zip).
4. Wait for the upload to finish. FLYER appears in your theme library as a
   draft. **Your live theme is untouched.**

## 2. Preview before you publish

Click **⋯ → Preview** on the FLYER card. Nothing your customers see changes
until you click Publish, so take your time here.

## 3. Set up your menus

FLYER uses Shopify's two default menus. If your store already has them, there is
nothing to do.

- **Header navigation** → the menu with the handle `main-menu`
- **Footer links** → the menu with the handle `footer`

You can point the header at a different menu in **Customize → Header → Menu**.

## 4. Make it yours

Open **Customize**. Everything below lives in **Theme settings** (the gear icon
at the bottom of the left sidebar):

| Where | What you get |
| --- | --- |
| Colors | Five colour schemes. Edit them, or add your own — each section can then pick which one it uses. |
| Typography | Heading and body fonts, sizes, scale, uppercase headings |
| Layout | Page width, margins, spacing between sections, grid gaps |
| Buttons / Inputs / Variant pills | Corner radius, border thickness and opacity, shadows |
| Product / Collection / Blog cards | Card or standard style, image ratio, text alignment, borders, shadows, colour scheme |
| Badges | Sale and sold-out labels, position on the card, corner radius |
| Animations | Reveal sections on scroll, hover effect |
| Cart | Drawer or page, order note, vendor, collection shown in an empty cart |
| Brand information | Headline, description and image, ready to drop into the footer |

### Colour schemes, in one sentence

Instead of picking colours section by section, you define a handful of schemes
once (background, text, button, button label, shadow), then each section just
chooses a scheme. Change a scheme and everything using it updates at once.

## 5. Build your pages

Click **Add section** on any template. FLYER ships 22 sections: slideshow, image
banner, image with text, multicolumn, collage, multirow, rich text, featured
collection, collection list, featured product, featured blog, collapsible
content (FAQ), video, email signup banner, newsletter, contact form, page
content, quick order list, country and language selectors, custom Liquid, and an
app container.

## 6. Publish

When you are happy: **⋯ → Publish** on the FLYER card.

---

## Good to know

- **Works without JavaScript.** Add to cart, variant selection, filters, search
  and the cart all work if scripts fail to load.
- **Accessible by default.** Colour schemes derive their secondary text and
  border colours so contrast stays above WCAG AA whatever palette you pick.
- **No external dependencies.** No jQuery, no CDN, no tracking.
